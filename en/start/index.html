Start here

This pilot includes one complete lesson: testing foundations, with reading, animated slides, and a practical lab. The course map identifies the later modules as planned and links the original lectures.

Choose your route

Section titled “Choose your route”

Students with basic programming: read the lesson, predict the boundary results, then write and run the lab test. Focus on connecting an assertion to a requirement.

Junior QA engineers: begin with the same rule and bug report. If automation is new, work through the provided JavaScript test line by line; you do not need React, Java, or a test framework installation.

Both routes have the same outcomes and assessment. Experienced learners can also investigate concurrent requests as a discussion exercise.

What you need

Section titled “What you need”

Reading, slides, and the interactive example work in a modern browser. The local lab requires Node.js 24. Check your installation:

The lab uses the built-in test runner. No npm install is necessary for the downloaded lab. Building this website is a separate maintainer task described in the repository README.

Use the course

Section titled “Use the course”
  • Start with the foundations lesson.
  • Open the slides from its top toolbar. Right arrow or Space advances through reveals; Left arrow goes back. The slide footer returns to the reading or switches language at the same slide.
  • Use the header language selector to keep the current topic in English or Russian.
  • Search is available in the built website, including this preview. Results follow the selected language.
  • Use the theme selector for light or dark appearance. Motion follows your system’s reduced-motion preference.
  • The reading contains the complete argument without animation. Use the browser’s Print command for a static handout.

Your first session

Section titled “Your first session”

Allow 80 minutes: 45 for guided discussion and examples, followed by 35 for the lab. For self-study, pause at every prediction before opening the answer. Finish with the exit questions and your explanation of what remains untested.
