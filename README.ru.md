Двуязычный курс для студентов с базовыми навыками программирования и начинающих
QA-инженеров, которые переходят к автоматизации. Первый урок переработан по PDF и записи:
полный текст на двух языках, по 48 анимированных слайдов, исходное задание на 20 кейсов
и отдельная практика регистрации на 35 минут. Оценка длительности лекции: 2 × 75 минут. Остальные модули явно отмечены как план. Исходные PDF, видео и примеры
приложений сохранены в прежних папках.

## Запуск полного предпросмотра

Нужен Node.js 24. При использовании nvm выполните `nvm use`.

```sh
npm ci
npm run build
npm run preview
```

Откройте <http://127.0.0.1:4321/testing-lectures/ru/> или
<http://127.0.0.1:4321/testing-lectures/en/>. Полный предпросмотр включает поиск,
слайды и скачиваемую практику. Поисковый индекс создаётся при сборке.

Для редактирования сайта с автоматическим обновлением: `npm run dev`.
Для слайдов в отдельных терминалах: `npm run slides:ru` (порт 3031) и
`npm run slides:en` (порт 3030). Ссылки сайта на слайды и ZIP работают в полном
собранном предпросмотре. Для переключения языка при редактировании слайдов
запустите оба сервера слайдов.

## Практика без установки сайта

В папке `labs/registration` выполните:

```sh
node --test starter/registration.test.mjs
```

Два исходных теста проходят. Добавьте проверку равенства, получите падение,
исправьте сравнение и запустите `node check.mjs`. На исходном коде эта команда
специально проваливает два граничных примера. [Инструкция и критерии](labs/registration/README.ru.md).

`npm test` проверяет учебные заготовки вместе с намеренным дефектом. Это команда
автора курса, а не студента после исправления своей копии.

## Проверка изменений

```sh
npm test
npm run lab:test
npm run lab:solution
npm run build
npx playwright install chromium
npm run test:e2e
```

Проверяются парность переводов и слайдов, локальные ссылки, переключение языков,
поиск, анимационные шаги, мобильная вёрстка, уменьшенное движение, доступность
и полный цикл работы со скачанным заданием. Автоматические проверки доступности
дополняют ручную проверку клавиатурой и визуальный просмотр.

## Как обновлять материалы

Тексты находятся в `website/src/content/docs/en/` и `ru/`; имена файлов совпадают.
Слайды находятся в `slides/foundations.en.md` и `foundations.ru.md`. Сохраняйте
одинаковые идентификаторы `name` и порядок слайдов. Меняйте обе версии вместе,
оставляйте общий код и переводите объяснения. Термины согласуйте со словарём.

Анимация управляется щелчками; автопроигрывания нет. Системная настройка уменьшения
движения отключает переходы. Текст урока содержит все объяснения без анимации;
его можно распечатать из браузера. Заметки преподавателя включаются в собранные
слайды, поэтому не храните там персональные данные или закрытые материалы.

## Публикация

Workflow `course.yml` собирает и проверяет сайт, сохраняя артефакт `bilingual-course`.
После попадания проверенного изменения в `master` он публикует этот артефакт в
существующую ветку `gh-pages`, запрашивает сборку Pages и проверяет её завершение.
Для повторной публикации можно вручную запустить workflow на `master` с параметром
`deploy`. Сохраняются текущий источник Pages (`gh-pages`, корень) и адрес
`https://brekelov.com/testing-lectures/`. Старый пример интерфейса больше не
перезаписывает сайт курса. Менять настройки Pages или создавать новый хостинг не нужно.

Базовый путь: `/testing-lectures/`. Для отдельного домена задайте `COURSE_BASE=/`
при сборке и браузерных тестах, обновите `site` в `website/astro.config.mjs`.
Слайды используют hash-маршруты для прямых ссылок на статическом хостинге.
Серверная часть, ключи, аналитика и аккаунты студентов не требуются.

Структура проекта, технические зависимости и примечание о патче `image-size`
описаны в [основном README](README.md). Подготовка занятия и критерии приёмки:
[заметки преподавателя](instructor/foundations.ru.md).

Разбор источников: [страницы PDF, метки записи и решения](instructor/lecture-01-source-map.md).
Прочитана полная автоматическая расшифровка, визуально просмотрены все 56 страниц PDF
и проверены два кадра записи; непрерывного просмотра всей записи со звуком не было.
Регистрация остаётся новым дополнительным упражнением, не заменяющим охват лекции.
