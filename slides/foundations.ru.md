# Превратим наблюдение в тест

```js
test('closes registration when the event is full', () => {
  const registered = 10;
  const capacity = 10;

  const actual = isRegistrationOpen(registered, capacity);

  assert.equal(actual, false);
});
```
<p v-click class="quiet">Дано состояние → выполняем действие → проверяем по правилу.</p>
