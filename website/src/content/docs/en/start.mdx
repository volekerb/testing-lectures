The rebuilt first lecture includes **48 animated slides per language**, a full reading, a source map and an assignment. It follows the original PDF and recording from requirements through reporting. The [course map](../course/) marks later modules as planned.

## Choose your route

**Programming students:** connect product goals to testable rules, then design cases at several scopes. The supporting lab turns one boundary into an executable regression check.

**Junior QA engineers:** use familiar reporting and case design as a starting point; practice explaining environments, boundaries and evidence. If automation is new, trace the provided JavaScript assertion before editing it.

Both routes share the full lecture and 20-case assignment. The registration lab supports the course and has a separate rubric.

## What you need

Reading, slides and the interactive example work in a modern browser. The supporting lab needs [Node.js 24](https://nodejs.org/en/download), a terminal and an editor. Check `node --version`. The downloaded lab needs no `npm install`; website development is a separate maintainer task in the README.

## Use the course

- Start with the [foundations reading](../lessons/foundations/); the [source map](../lessons/foundations-sources/) links PDF topics to recording timestamps.
- Right arrow or Space reveals slide content; Left arrow goes back. The footer returns to the reading or switches language at the same slide.
- The website language selector keeps the topic. Search results follow the selected language.
- Light/dark appearance and reduced-motion preferences are supported. The reading is the complete static alternative and can be printed from the browser.

## Plan your sessions

Allow **two 75-minute sessions**, with a break after slide 24. Session one covers the product, lifecycle, environments and scopes; session two covers planning, design, defects and reports. This is an estimate awaiting classroom feedback.

Prepare the main **20-case assignment** afterwards. Add the separate **35-minute registration lab** to practice the failure/fix loop. Do not count designed but unexecuted cases as passed. The website does not collect submissions.
