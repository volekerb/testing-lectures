В пилоте полностью готов один урок: **основы тестирования**, с текстом, анимированными слайдами и практикой. В [программе](../course/) отмечены будущие модули и сохранены ссылки на исходные лекции.

## Выберите маршрут

**Студентам с базовыми навыками программирования:** прочитайте урок, предскажите результаты на границе, затем напишите и запустите тест. Главная задача: связать утверждение в тесте с требованием.

**Начинающим QA-инженерам:** начните с того же правила и отчёта о дефекте. Если автоматизация незнакома, разберите готовый JavaScript-тест по строкам. React, Java и установка тестового фреймворка не нужны.

Результаты обучения и критерии проверки одинаковы для обоих маршрутов. Более опытные участники могут дополнительно обсудить конкурентные запросы.

## Что понадобится

Текст, слайды и интерактивный пример работают в современном браузере. Для локальной практики нужен [Node.js 24](https://nodejs.org/en/download). Проверьте установку:

```sh
node --version
```

Практика использует встроенный тестовый раннер. Для скачанного задания не нужен `npm install`. Сборка самого сайта является отдельной задачей автора и описана в README репозитория.

## Как пользоваться курсом

- Начните с [урока об основах](../lessons/foundations/).
- Откройте слайды по ссылке в начале урока. Стрелка вправо или пробел раскрывает следующий шаг; стрелка влево возвращает назад. Внизу слайда есть возврат к тексту и переключение языка на том же слайде.
- Переключатель языка в шапке сохраняет текущую тему.
- Поиск работает в собранном сайте, включая этот предпросмотр. Язык результатов соответствует выбранному языку.
- Выберите светлую или тёмную тему. Анимация учитывает системную настройку уменьшения движения.
- В тексте есть всё содержание без анимации. Команда «Печать» в браузере позволяет получить статический конспект.

## Первое занятие

Заложите **80 минут**: 45 на обсуждение и примеры, ещё 35 на практику. При самостоятельном обучении делайте прогноз до раскрытия ответа. В конце ответьте на вопросы и объясните, что осталось непроверенным.
