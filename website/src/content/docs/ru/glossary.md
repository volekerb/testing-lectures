---

Это определения для курса. В командах названия границ тестирования могут отличаться: договаривайтесь о границе и цели, а не только о термине.

| English | Русский | Значение |
| --- | --- | --- |
| Requirement | Требование | Согласованное поведение или ограничение. |
| Test oracle | Тестовый оракул | Источник, по которому определяют ожидаемый результат. |
| Expected result | Ожидаемый результат | То, что должно произойти согласно оракулу. |
| Actual result | Фактический результат | То, что наблюдаем при выполнении системы. |
| Defect | Дефект | Недостаток, который может вызвать расхождение с требованием. |
| Failure | Отказ / наблюдаемое нарушение | Наблюдаемая неспособность выполнить требуемое поведение. Падение теста также может быть вызвано ошибкой теста или окружения. |
| Assertion | Утверждение в тесте | Исполняемая проверка ожидаемого условия. |
| Boundary-value analysis | Анализ граничных значений | Выбор примеров на границе решения и рядом с ней. |
| Regression testing | Регрессионное тестирование | Проверка нежелательных изменений поведения после правок. |
| Unit test | Модульный тест | Проверка небольшой изолированной единицы, например нашей чистой функции. |
| Integration test | Интеграционный тест | Проверка взаимодействий между компонентами или системами. |
| End-to-end test | Сквозной тест | Проверка полного сценария в заданной границе системы; UI не обязателен. |
| Risk | Риск | Возможный неблагоприятный исход с учётом ущерба и вероятности. |
| Test evidence | Свидетельства тестирования | Наблюдения и артефакты, поддерживающие вывод в определённых границах. |

## Дополнительные термины лекции

| English | Русский | Значение |
| --- | --- | --- |
| Static testing | Статическое тестирование | Оценка рабочего материала без запуска программного продукта. |
| Dynamic testing | Динамическое тестирование | Оценка поведения через выполнение программы. |
| Equivalence partitioning | Классы эквивалентности | Группировка входов с предполагаемым сходным поведением для выбранного правила. |
| Decision table | Таблица решений | Связь комбинаций условий с ожидаемыми исходами. |
| Pairwise testing | Попарное тестирование | Выбор комбинаций, покрывающих каждую пару значений факторов. |
| Exploratory testing | Исследовательское тестирование | Совместное обучение, проектирование и выполнение вокруг цели исследования. |
| Test double | Тестовая замена | Замена зависимости с явно ограниченным поведением. |
| Negative test case | Негативный тест-кейс | Проверяет отказ или восстановление; правильная обработка означает успех кейса. |
| Confirmation testing | Подтверждение исправления | Проверка устранения конкретного дефекта. |
| Smoke suite | Smoke-набор | Выбранные критичные проверки для решения о продолжении работы. |
| Severity | Серьёзность | Степень влияния проблемы. |
| Priority | Приоритет | Очередность или срочность работы с учётом контекста. |
| Blocked | Заблокирован | Нельзя осмысленно выполнить из-за недоступного предусловия. |
| Flaky result | Нестабильный результат | Непостоянные результаты, требующие исследования продукта, теста и среды. |
| Test isolation | Изоляция тестов | Предотвращение нежелательного влияния через общее состояние или ресурсы. |
| Entry / exit criteria | Критерии входа / выхода | Согласованные условия начала или завершения тестовой деятельности. |
