---
title: Двуязычный словарь
description: Рабочие определения, которые мы последовательно используем в курсе.
---

Это определения для курса. В командах названия границ тестирования могут отличаться: договаривайтесь о границе и цели, а не только о термине.

| English | Русский | Значение |
| --- | --- | --- |
| Requirement | Требование | Согласованное поведение или ограничение. |
| Test oracle | Тестовый оракул | Источник, по которому определяют ожидаемый результат. |
| Expected result | Ожидаемый результат | То, что должно произойти согласно оракулу. |
| Actual result | Фактический результат | То, что наблюдаем при выполнении системы. |
| Defect | Дефект | Недостаток, который может вызвать расхождение с требованием. |
| Failure | Отказ / наблюдаемое нарушение | Наблюдаемая неспособность выполнить требуемое поведение. Падение теста также может быть вызвано ошибкой теста или окружения. |
| Assertion | Утверждение в тесте | Исполняемая проверка ожидаемого условия. |
| Boundary-value analysis | Анализ граничных значений | Выбор примеров на границе решения и рядом с ней. |
| Regression testing | Регрессионное тестирование | Проверка нежелательных изменений поведения после правок. |
| Unit test | Модульный тест | Проверка небольшой изолированной единицы, например нашей чистой функции. |
| Integration test | Интеграционный тест | Проверка взаимодействий между компонентами или системами. |
| End-to-end test | Сквозной тест | Проверка пользовательского сценария через нужные слои системы. |
| Risk | Риск | Возможный неблагоприятный исход с учётом ущерба и вероятности. |
| Test evidence | Свидетельства тестирования | Наблюдения и артефакты, поддерживающие вывод в определённых границах. |
